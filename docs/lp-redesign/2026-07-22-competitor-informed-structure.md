## 0. 結論（構成の方針）

現行LPの型（Header → Promo → Hero → YOUR CONCERN → Our Pride → Founder → PRICING → PROCESS → FAQ → Closing → Footer）は**土台として正しい**。LE LABO的な「プロセスを見せる」「余白で語る」トーンも競合にない資産。

競合分析が示す課題は構成の作り直しではなく、**「中身では勝っているのに、見せ方・具体性で負けている」信頼要素の再配置**。そのため提案は「セクション追加1つ＋既存セクションの拡張」に絞り、LP全体を肥大化させない。

## 3. 新規・拡張要素のドラフトコピー

トーン基準: `bispoke-brand-guidelines.md`（LE LABOベンチマーク・体言止め・端的・素材と工程で語る）。NG表現（即日／最短／No.1／業界最安／お客様の声）・競合名の名指しは使用していない。

### 3-1. 信頼の帯（NEW・Hero直下）

横並び5項目。既存の価格セクションにある6バッジ（送料無料／見積もり無料／新品仕上げ込み／歪み・石留め点検込み／1年保証／輸送保険付き）のうち、**保証・信頼に関わる項目だけをHero直下に前倒しする**（価格セクションのバッジは維持でよい＝重複配置で問題ない。信頼情報は繰り返し見せる方が競合比で強くなる）。

```
送料無料（往復）　|　見積もり後の追加料金なし　|　1年保証　|　輸送保険付き　|　国家資格保有の職人
```

各項目はモノスペース体でラベル＋游ゴシックで一行説明、の2階層。例:

```
FREE SHIPPING（往復）
全国どこでも、送料は当社負担です。

NO HIDDEN FEES
お見積もり後の追加料金は、一切いただきません。

1-YEAR WARRANTY
仕立て完了後1年間、無償で保証します。
```

「輸送保険付き」「国家資格保有の職人」の一行説明は、保険会社名・資格名が確認でき次第、具体名に差し替える（§2参照）。

### 3-2. Our Pride 拡張（「なぜ直せるのか」）

resize LPの既存Our Prideは「国内の職人が多数在籍」「国家資格保有」「手作業」という職人紹介止まり。repair LPには技術的根拠（「機械のレーザー溶接ではなく、職人の伝統的なロウ付け」）があるが、resize LPにはない。以下を追加する:

```
見出し: 他店で断られた指輪も、直せる理由。

本文: 石つきのリング、消えやすい刻印、大きすぎるサイズ差。
断られる理由の多くは、機械加工の限界です。
RETOLD TOKYOは機械任せにせず、一本ずつ状態を見極め、
手作業でサイズを仕立て直します。
```

既存の「多くの企業では、ジュエリー職人が分業されており〜」の一文はそのまま活かし、上記を前段に挿入する形が自然。

```
A. 全国どこからでも、同じ品質でお受けするためです。

   確認が取れるまでは既存回答「まずはLINEでお写真をお送りください」を維持）
```

### 3-4. 地金買取りクロスセル（PRICING or FAQ付近・一言）

ブランドガイドライン上は既存サービスとして定義されている（「次の輝きへ、託す」）が、resize/repair LPには未掲載。運用可否確認後、価格表の直後などに一文で追加:

```
サイズ直しで生じた余分な地金は、次の輝きへ託すこともできます。
ご希望の方はLINEでご相談ください。
```

- [ ] 柔軟納期割引（例: 通常1ヶ月→6週間で◯%OFF）の新オファー導入。価格・利益構造に影響するため`bispoke-operations.md`の判断基準上、CEO承認が必要

## 6. 変更しないもの（既存の強みとして維持）

- Founder（創業者の思い）セクション全体 — LE LABO的なナラティブラグジュアリーの核であり、競合に同等のものはない
- 一式フラット価格（「お直し一式」表記） — 競合のほぼ全社が「◯円〜＋地金追加」の後出し型である中、当社の構造的な差別化
- まとめ割10%OFF — 競合内で明示している例は確認できず、独自性を維持
- 全体のセクション数・順序の骨格 — 「情報を詰め込みすぎない」というLE LABOトーンを守るため、新規セクションは信頼の帯1つに絞る
